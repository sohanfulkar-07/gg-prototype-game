# SwordStrike

**Official Game Name:** SwordStrike  
**Current Game Version:** 5.3.47  
**Android Package ID:** `com.sohanfulkar.swordstrike`  
**Target Engine:** Godot Engine 4.7.2 (stable.official)  
**Render Pipeline:** GL Compatibility Mobile  
**Genre:** 3D Fantasy Action RPG  

## Overview
SwordStrike is a 3D mobile fantasy action RPG featuring third-person real-time combat, multi-hit sword combos, a rotatable camera with collision prevention, quests, town hub, merchant trading, and an immersive 3D cinematic opening sequence.
